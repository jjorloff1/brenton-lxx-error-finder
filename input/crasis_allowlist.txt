# Crasis Allowlist
# Known crasis forms with their CORRECT breathing and accenting.
# One word per line (with correct diacritics).
# Comments start with #
#
# Crasis = contraction of two words, typically:
# - καί + vowel-initial word
# - τά/τό/τοῦ + vowel-initial word
#
# The breathing mark indicates the original second word's breathing.
# Rough breathing = original word had rough breathing
# Smooth breathing (coronis) = original word had smooth breathing
